# JUKEBOX

## Nessa pasta se encontram todos os arquivos de áudio utilizados pela jukebox do BOT

- Este diretório é necessário para que o sistema da jukebox funcione corretamente, favor não Apagá-lo!
- Organize os áudios em subpastas (categorias), por exemplo: `gospel`, `rock`, `nacional`, `sertanejo`, etc.
- Formatos suportados: mp3, wav, m4a, ogg, opus, flac, mp4, webm e aac
- Use o comando `/music jukebox` no Discord e escolha a categoria (nome da subpasta) para iniciar a playlist
